# castobject -- whole-corpus decompile-all hunks, option on vs off, every one classified

Both arms are the same build (this branch on origin/main 29cfedee0), whole
binary, `kuna decompile-all` at the default mode, `--option castobject off`
against the default:
  A. the castbench set: 45 decbench binaries (coreutils fmt ls sort du cp tail wc,
     grep, gzip, diffutils cmp diff diff3 sdiff, tar, find) x O0/O2/O2-noinline.
     With the option off every file is byte-identical to the castbench arm of
     origin/main 0096e984d. 3 binaries change.
  B. 36 more decbench binaries, 11,603 functions: the 24 that import
     waitpid/wait (sysvinit logsave x3, sulogin, killall5, shutdown x2, init x2;
     coreutils timeout x3, split; shadow su x2, login, vipw x2; cronie crontab
     x2, crond x2; dpkg-trigger O2; bash O2) and the 12 the review read
     (ginstall O0/O2, dash O0/O2, dpkg-divert O0/O2, useradd O0, passwd O0, scp
     O0, sftp-server O0, id O0, mkdir O2). 10 change.

Classes (every changed line is one of these):
  DECL   the out-parameter local's declaration: unsigned int/uint4 -> int/int4
  CALL   the call that fills it passes &v uncast: (int *)&v -> &v
  SHIFT  an arithmetic shift of it reads it uncast: (int)v >> 8 -> v >> 8
  USUF   a bit test on it marks its constant unsigned: v & 0x7f -> v & 0x7fU
         (the printer states the unsigned AND on the constant instead of on a
         cast; the value is the same)
  STORE  a store of it through a pointer spells the pointee at the new sign:
         *(unsigned int *)(p + 4) = v1 -> *(int *)(p + 4) = v1 (same bits stored)
  MERGE  a register copy of it takes int too and merges with another int register
         variable whose live range it does not overlap (split O0 sub_3e43: the
         errno temporary and the status copy become one `int v1`); one
         declaration fewer, and every later register variable is renumbered by
         one (RENUM). Register locals are not in the --json variables.

Every function the option changes in A declares `int stat_loc` in IDA at the
same address (sort -O0 0x48cf, diff -O0 0x11e1b, tar -O0 0x32ca8 0x33179
0x343ea 0x345e7).

Casts: A 35,588 -> 35,572 on the 4,815 functions shared with IDA (6 fewer, 0 more).
