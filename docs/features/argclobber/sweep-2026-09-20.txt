Hunk classes
----------------------------------------------------------------------
Raw `diff` counts are large (bash -142/+137, e2fsck -115/+111) only because
dropping one declaration renumbers every `vN` in that function. With names
normalised (`sed -E 's/\bv[0-9]+\b/V/g'`) the whole corpus delta is:

  openssh O0   x11   -10 / +4        openssh O2      x2   -5  / +2
  openssh O2ni x2    -7  / +4        coreutils fmt   x2   -11 / +4
  bash O2      -15/+10, O2ni -16/+11 e2fsck O2            -9  / +5
  u-boot O2ni        -2  / +1

and each of those lines is one of seven classes, all inside the option's
documented effect:

  1. the dropped trailing argument (21)
  2. the dead idiv remainder that fed it, and its copies
  3. the phantom register declaration and its copy
  4. declaration block reordering once one declaration is gone
  5. one folded single-use divisor (bash)
  6. a while re-rendered as a for, once the dead loop-tail copy went (11 openssh permute_args)
  7. the PRECEDING call's return narrowing where that call was the register's only writer: bash expand_prompt `v = xmalloc(n); a = SUB168(v,8);` -> `v = (char *)xmalloc(n);` (2), and the two SUB164 extractions that fed it

No hunk falls outside them.
